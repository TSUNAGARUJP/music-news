# 洋楽ネタ・デイリー

海外の音楽メディア、日本の洋楽メディア、一般メディアのエンタメ欄、来日情報（招聘会社・ニュース検索）の情報源を毎日集め、Claudeが「今日のリールネタ」トップ3、来日情報、ジャンル別の次点、いつでも使える雑学ネタ（サイトのみ）を選んで、LINEと閲覧サイトに届けるツールです。

## 毎日の流れ

1. 11:30ごろ（日本時間）にGitHub Actionsが自動で起動する
2. 各メディアのRSSから過去30時間の記事を集める
3. Claude Haiku 4.5 が英語・日本語の記事を話題ごとにまとめ、何媒体が報じたか（うち日本の媒体・一般メディア）を数える
4. YouTubeの音楽チャート（日本・米国・英国）と関連動画の再生数を調べる
5. Claude Opus 5.5 がトップ3・来日情報・次点を選び、日本語のまとめとリール案を書く
6. 閲覧サイトを更新し、LINEに通知する（12時前後に届きます）

## よく使う操作

- **今すぐ実行する**：「Actions」タブ →「洋楽ネタ デイリー」→「Run workflow」
- **設定を変える**：`config.toml` を開いて鉛筆マークから編集し、「Commit changes」で保存
  - 選定基準：`[selection]` の `criteria`
  - メディアの追加・削除：`[[sources]]` のまとまり
  - 比較をやめる：`[models]` の `compare` を `""` にする
- **失敗したとき**：LINEにエラー通知が届きます。リンク先のログで赤い×の付いた手順を開き、エラー文をClaudeに伝えてください

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `config.toml` | 設定（メディア一覧、選定基準、モデル） |
| `main.py` | 毎日の処理の本体 |
| `collect.py` | RSSの取得（自動検出・Googleニュース経由の予備つき） |
| `youtube.py` | YouTubeの再生数・音楽チャート |
| `ai.py` | Claudeへの指示（グループ化、選定と執筆） |
| `notify.py` | LINE通知 |
| `site_builder.py` | 閲覧サイトの生成 |
| `data/` | 毎日の結果（自動で増えていきます） |

## 注意

- 閲覧サイトは検索エンジンに載らない設定ですが、URLを知っていれば誰でも見られます。
- 60日間リポジトリに更新がないと、GitHubが自動実行を止めることがあります。毎日の結果保存が更新にあたるため通常は問題ありませんが、停止の通知メールが来たら「Actions」タブから再開してください。
